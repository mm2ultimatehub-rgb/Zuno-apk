# ZUNO APK

**Mobile Android Studio** — GitHub Pages üzerinde çalışacak, telefon odaklı Android proje çalışma alanı.

## Başlangıç
- GitHub Pages'i repository Settings → Pages bölümünden `main` / root olarak etkinleştir.
- `index.html` doğrudan tarayıcıda çalışan arayüzdür.
- Proje listesi ve editör taslağı cihazın localStorage alanında tutulur.

## Mevcut prototip kapsamı
- Yeni proje metadata formu
- Dosya seçme ve metin dosyalarını editörde açma
- Yerel taslak kaydetme
- Mobil koyu arayüz ve sayfa navigasyonu
- Backend URL ayarı için arayüz

## Önemli
Bu repository'deki sürüm **henüz gerçek APK derlemez**. ZIP açma, Android SDK/Gradle build, APK imzalama, gerçek build backend ve release/update akışı sonraki geliştirme aşamalarıdır. APK üretildiğini veya imzalandığını iddia etmez.
